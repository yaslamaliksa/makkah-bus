# دليل الحافلات — إنجاز وابي تهامة

نسخة جاهزة للرفع إلى GitHub وتشغيلها على GitHub Pages. تضم أحدث تصميم وشعار ونافذة خريطة مكة التفاعلية. لا تحتاج إلى تثبيت حزم أو تشغيل عملية بناء.

## الرفع من موقع GitHub

1. فك ضغط الملف `makkah-bus-github.zip` على جهازك.
2. أنشئ مستودعًا جديدًا في GitHub أو افتح المستودع المطلوب.
3. اختر **Add file → Upload files**، ثم ارفع محتويات المجلد المستخرج إلى جذر المستودع.
4. تأكد أن `index.html` يظهر مباشرة في الصفحة الرئيسية للمستودع، وليس داخل مجلد إضافي. لا ترفع ملف ZIP وحده.
5. احفظ الملفات عبر **Commit changes**.
6. افتح **Settings → Pages**.
7. عند **Source** اختر **Deploy from a branch**.
8. اختر الفرع **main** والمجلد **/(root)**، ثم اضغط **Save**.
9. بعد اكتمال النشر سيظهر رابط الموقع في صفحة **Pages**. قد يستغرق ظهوره بضع دقائق.

الملف `.nojekyll` مرفق لتشغيل الموقع بوصفه ملفات ثابتة. إذا أخفى نظامك الملفات التي تبدأ بنقطة، يمكنك إنشاء ملف فارغ بهذا الاسم في جذر المستودع عبر **Add file → Create new file**.

## تشغيل نسخة محلية

للمعاينة الأساسية افتح `index.html`. ولتشغيله عبر خادم محلي عند توفر Python:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`. تحديد الموقع يتطلب HTTPS أو localhost، وإذن المستخدم في المتصفح.

## الملفات الأساسية

- `index.html`: الصفحة الرئيسية وبطاقاتها.
- `styles.css` و`app.js`: تنسيق الموقع وتفاعلاته.
- `makkah-map.css` و`makkah-map.js`: نافذة خريطة مكة التفاعلية والبحث والمعالم وتحديد الموقع.
- `assets/`: الصور والخطوط وأيقونة الموقع وملفات Leaflet وتراخيصها.

## تعديل البيانات

- مواعيد الحافلات ومساراتها: مصفوفة `routes` في `app.js`.
- معالم مكة: مصفوفة `places` في `makkah-map.js`.
- الاسم والشعار والنصوص الأساسية: `index.html`.

المواعيد والمسارات الحالية توضيحية. المساعدة الصوتية تدعم العبارات الجاهزة، ويتوقف التعرف والقراءة الصوتية على دعم المتصفح. صور الخريطة تحتاج إلى اتصال بالإنترنت، ويظهر موقع المستخدم بعد منحه الإذن.

مصادر الأصول وإشعاراتها في `THIRD-PARTY-NOTICES.md`.

## اللغات والحركات

يمكن تبديل لغة الواجهة من زر اللغة إلى العربية أو الإنجليزية أو الأردية (باكستان) أو الصينية المبسطة. يُحفَظ الاختيار في المتصفح مع دعم اتجاهي العرض. ترجمة الموقع في `translations.js` ومحركها في `i18n.js`.

الحركات والتحسينات في `enhancements.css` و`motion.js`، وتحترم إعداد تقليل الحركة في الجهاز. لغة المساعدة الصوتية مستقلة عن لغة الواجهة. أسماء الشركة والشعار والمواعيد نفسها محفوظة.
